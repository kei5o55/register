### レジアプリケーション
　同人イベント向けのレジアプリケーションです．
 単品・セット頒布に対応しており，イベント単位で売り上げ・頒布数を管理し，グラフによる可視化機能を実装しています

### 制作目的
- モダンな Web 技術（TypeScript / React）を用いた 実践的なアプリケーション開発経験の習得
- 創作活動を支えるツールの制作を通じて，自身および他者の創作活動の支援につながるプロダクトの開発を目指す

### 主な機能
- レジ機能
  - 商品の選択・カート追加
  - 商品の在庫数チェック
  - 合計金額の自動計算
  - 会計処理
  - 売上履歴の保存・一覧表示
  - 売上ごとの詳細表示
- 頒布物管理
  - 頒布物の追加
  - 頒布物情報（名称・価格）および在庫数の編集
  - 頒布物の削除
  - セット頒布(バンドル）の作成・管理
-イベント管理
  - 即売イベントの追加
  - イベント日時やメモの追加
  - イベントごとの売上金額＋個数集計
  - 時間別売上グラフ
  - 頒布物別頒布数グラフ
 
### 設計のポイント
- 集計ロジックと表示ロジックを分離
- イベント単位での売上データ設計
- バンドル内頒布物を展開して在庫・集計に反映
- ISO形式で日時を保存し，時間別の集計に対応
    
### 使用技術
- **TypeScript**
  - 静的型付けによる安全性の高い実装を行い
    バグの抑制および保守性・拡張性を意識した設計を実施

- **React**
  - コンポーネント指向に基づく画面構成を採用し，UIの再利用性と拡張性を考慮した実装
 
- **localstrage**
  - プロトタイプ段階ではlocalstrageを使用し売り上げを保存
  - 保存したデータを用いた集計およびグラフ描画を実装
  - 将来的にDBへ移行し，複数端末での管理を目標
